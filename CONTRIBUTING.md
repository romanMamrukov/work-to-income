# Contributing

Work to Income is in product validation. Discuss substantial features before implementation so the product remains focused on the work-to-income workflow.

## Development

1. Create a branch from `main`.
2. Install dependencies with `npm ci`.
3. Make a focused change with tests for domain behaviour.
4. Run `npm test`, `npm run lint` and `npm run build`.
5. Open a pull request describing user impact, data-schema impact and screenshots for interface changes.

Do not include real invoices, customer data, credentials, generated backups or database files in examples and tests.
